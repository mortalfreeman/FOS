# Unstable Features (Экспериментальные фичи)

Эта папка содержит фичи, которые находятся в разработке и могут быть нестабильными.

## Содержимое:
- `xstd/` — чистая ассемблерная реализация рантайма (без libc).
- `wasm/` — компиляция X-lang в WebAssembly (не работает).

Для стабильной сборки используйте `clang -static` (как описано в главном README).
