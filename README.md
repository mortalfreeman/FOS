# FOS (Free Open Source Software)

Экосистема FOS включает:
- **X-lang** (компилятор `xc` на Rust + LLVM)
- **xlang-lsp** (сервер для Neovim)

## Сборка
```bash
git clone https://github.com/mortalfreeman/FOS.git
cd FOS
make install
```
